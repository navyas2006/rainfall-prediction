About the Project

A simple, explainable, end-to-end machine learning project — built for learning and demonstration.

Goal

Predict whether rainfall will occur on a given day using historical weather station data from across India.

Dataset

Daily weather records including temperature, wind, pressure, elevation, and location, collected from Indian weather stations.

Approach

A supervised classification model learns the relationship between weather conditions and rainfall occurrence.

Machine Learning

How the prediction engine works under the hood

Random Forest Classifier

An ensemble of many decision trees votes together to classify each day as "Rainfall" or "No Rainfall", which makes it robust and accurate.

Data Cleaning

Missing values are filled, categorical fields (month, season, state) are encoded, and numeric features are scaled before training.

Evaluation

The model is tested on unseen data and evaluated using accuracy, a classification report, and a confusion matrix.

Features

What this application offers

Web Interface

Clean Flask + HTML/CSS/JS interface, no frameworks needed.

Consistent Preprocessing

The exact same preprocessing pipeline is used for training and prediction — no feature mismatch.

Confidence Score

Each prediction includes a model confidence percentage.

Input Validation

Form fields are validated on both the browser and server side.
